# Experimental Android64 AI macro recorder: source candidate only

This source combines beta.15's SHARE/HYPE/GDB/safety changes with a **new opt-in gameplay experiment**. It does not replace xdBot, install an AI model, contact a cloud provider, or restore the XD TOOLS pause panel or companion FPS/deaths HUD. Do not release or install from this source ZIP. A new Android64 Geode CI build and a disposable-level phone test are required.

## Intended beta.19 flow (not phone-verified)

1. Enter a disposable normal-mode classic cube level with xdBot loaded. Press Pause. A separate START AI button is now in the **Pause menu**, not on gameplay; the old XD TOOLS panel and FPS/deaths HUD stay absent. Confirm the experimental heuristic prompt, then tap RESUME. The current level resets to frame zero and tries bounded jump timings. Merely entering or pausing a level does nothing. Turning the Geode permission OFF stops a running attempt; STOP AI in Pause or manual input/restart/quit cancels a run without silently changing the preference. The setting defaults OFF but START AI confirmation explicitly enables it.
2. This is only a local single-button death-timing heuristic (max 80 attempts), not level vision or a general solver. Practice/dual/platformer are refused. An error popup after Resume now names the reason rather than blaming xdBot and mode together; send its exact text and a redacted screenshot if it recurs.
3. On a first reported completion, nothing is saved. Re-enter the same level, Pause and tap VERIFY AI, confirm and Resume. Only after matching reported completion timing and inputs is a local `companion-ai-<level>-<n>.gdr.json` candidate written to xdBot's macro folder. Import/replay remains unverified. No website upload occurs.
4. Beta.18 compiled in Actions run 39454823825 but showed a generic start failure in the user's screenshot. Beta.19 source/host checks are not a native build or phone test. Do not install the ZIP or relabel beta.18's `.geode`.

## Technical and safety limits

- `src/ai/AiMacroSearch.*`: bounded exploratory timing core, host-tested only against toy hazards; no neural network. `src/ai/AiGameplayAndroid.cpp`: Geode Android hooks (new and unverified); `src/ai/AiReplayJson.*`: independent legacy GDR JSON compatibility candidate. No xdBot source/assets, third-party AI-mod code, passwords, or private macros are included.
- The intended controller only handles player-1 jump-button pulses. Ship/wave/ball/portals may not be solvable with this simplistic strategy; dual/platformer/practice are explicitly refused. An 'any selected level' **target** does not mean every level will complete. Cross-mode planning, physics model, bounded learning memory, replay metadata accuracy, and native replay compatibility need significant further work.
- No network AI or gameplay screenshot transmission is configured. A future cloud option would require a service, explicit per-session consent, credential storage design, latency and privacy review. The provided video demonstrates an external interactive agent, not a ready-to-embed Android model.
- Hook signatures were checked against public Geode Geometry Dash 2.2081 bindings, including `GJBaseGameLayer::processCommands(float,bool,bool)`, `GJBaseGameLayer::handleButton(bool,int,bool)`, and PlayLayer reset/death/completion. Hook ordering against xdBot, runtime input timing, file import and level completion timing have **not** been verified on the target game. Do not use on a valued save or claim legitimate unassisted level completion.
