# Draft GitHub post: Windows and iOS testers wanted

**Title:** Testers wanted: xdBot Companion on Windows and iOS (development builds only)

We are preparing independent Windows and iOS ports of **xdBot Companion** (`jimmy_1234ha.xdbot-companion`). It adds an opt-in Share Macros action to xdBot's Load Macro window. We need volunteers with **Geometry Dash 2.2081, Geode, and xdBot v2.7.7** on their own device.

**Windows/iOS CI artifacts exist, but are UNREVIEWED and UNTESTED. Do not install them yet.** The currently downloadable `xdbot-companion.geode` outside CI contains **Android64 only**. After independent source review, specific volunteers can receive platform-labelled development artifacts and test instructions; this is not a public release.

If you can help, reply with **Windows or iOS**, your OS version, Geometry Dash version, Geode version, xdBot version, and whether you can share a *redacted* screenshot/crash log. No account credentials, personal paths, or macro files are needed. On iOS, please also say whether you already have a working Geode + xdBot setup and a way to install a test mod.

When a build is available, we will ask testers to verify: (1) the game opens and the xdBot Load Macro screen stays stable; (2) the button fits alongside the existing controls; (3) old and newly saved macros appear; (4) selecting one macro and then two opens the **native OS sharing UI** and the recipient receives the correct file(s); (5) cancelling does not crash or send anything.

Do not upload private macros or post unredacted storage paths. The add-on must never upload anything automatically. Testing is voluntary, and test builds are not stable releases or evidence of Index approval. Independent source review is required before any tester installation.
