# Hyperbolus Android development branch

The user-facing mobile GitHub/Codespaces steps are provided in chat alongside the actual source ZIP. Do not use old beta.4 port-preview instructions for this source. The ZIP belongs on a separate `hyperbolus-android` branch. `.github/workflows/hyperbolus-android.yml` builds an Android64-only developer candidate; it does not publish a release. No claim of runtime website login, upload or download is justified before a real-phone test.
