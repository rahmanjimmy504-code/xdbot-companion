# xdBot Companion — Android64 HYPE + GDB developer candidate

Developer: Jimmy_1234ha. Separate opt-in Geode add-on. The companion macro panel offers HYPE for Hyperbolus and GDB for https://gdbrowser.com/; each site has its own in-game Android WebView and a switch to the other. Selected macros are never sent to GD Browser automatically. Hyperbolus website file attachment requires confirmation and its own form submission; local Android EXPORT uses a native document save picker. The original companion SHARE action remains. Small original icons augment rather than replace labels in the macro panel. Beta.9 native build, icon layout and new website flow are unreviewed and untested on a phone. Android32, Windows and iOS website ports remain pending. Not a release.
