# xdBot Companion v1.2.5
Independent Android64 add-on for Geometry Dash 2.2081 and Geode 5.10.1. It contains none of xdBot's compiled binaries, source, sounds or images.

Open xdBot's **Load Macro** window and tap the companion's **SHARE MACROS** button (in a compact light-outlined brown plaque beside SELECT ALL in the bottom row). A blue picker lists saved macros; tap files to select, change pages, use ALL or CLEAR, then SHARE. Android opens its normal share sheet with one attachment or multiple attachments. Old saved macros are available, not only freshly recorded ones. If the xdBot UI button is not detected on your device, use **XD TOOLS > MACROS** from the pause menu as a fallback.

The optional post-save Share now prompt and small HUD remain available. No file is uploaded automatically. The companion reads xdBot's configured Macro Save Location but never edits macro contents or gameplay input. Sharing uses the Android launcher's content provider; compatibility and UI placement require real-device testing.

Developer: **Jimmy_1234ha**. v1.2.5 has a new mod ID, so uninstall the older companion first; your companion settings will return to defaults. Official xdBot stays installed.
