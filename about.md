# xdBot Companion — Hyperbolus Android development candidate

Developer: Jimmy_1234ha. This separate Geode add-on's Android browser is a native WebView Dialog over the game. Login remains on Hyperbolus's own webpage. The user alone attaches a macro and submits the site's upload form; account downloads use an Android save picker and stream to the URI chosen by the user. No mod-owned password field or automatic upload exists. The Android64 beta.5 phone picker failed. Beta.6 replaces it with a URI-based SAF picker and enables local Android export; beta.6 CI and phone tests are pending. Android32, Windows and iOS browser ports are not implemented. Not a release.
